# VS Code 常用快捷键（Windows）

## 最常用

- `Ctrl + Shift + P`：命令面板
- `Ctrl + P`：快速打开文件
- `Ctrl + Shift + F`：全局搜索
- `Ctrl + 反引号`：打开/关闭终端
- `Ctrl + B`：打开/关闭侧边栏
- `Ctrl + /`：行注释/取消注释
- `Alt + ↑ / ↓`：向上/向下移动当前行
- `Shift + Alt + ↑ / ↓`：向上/向下复制当前行
- `Ctrl + D`：选中下一个相同内容
- `F12`：转到定义
- `Shift + Alt + F`：格式化整个文档
- `Ctrl + S`：保存

## 编辑操作

- `Ctrl + X`：剪切
- `Ctrl + C`：复制
- `Ctrl + V`：粘贴
- `Ctrl + Z`：撤销
- `Ctrl + Y`：重做
- `Ctrl + F`：当前文件查找
- `Ctrl + H`：当前文件替换
- `Ctrl + G`：跳转到指定行
- `Ctrl + Shift + K`：删除当前行
- `Ctrl + Enter`：在当前行下方插入新行
- `Ctrl + Shift + Enter`：在当前行上方插入新行
- `Ctrl + ]`：增加缩进
- `Ctrl + [`：减少缩进
- `Shift + Alt + A`：块注释
- `Ctrl + Backspace`：删除前一个单词
- `Ctrl + Delete`：删除后一个单词
- `Home`：行首
- `End`：行尾
- `Ctrl + Home`：文件开头
- `Ctrl + End`：文件结尾

## 多光标

- `Alt + 鼠标点击`：添加多个光标
- `Ctrl + Alt + ↑ / ↓`：向上/向下添加光标
- `Ctrl + D`：选中下一个相同内容
- `Ctrl + Shift + L`：选中所有相同内容
- `Ctrl + U`：撤销上一次光标操作

## 导航与跳转

- `Ctrl + P`：快速打开文件
- `Ctrl + Shift + O`：跳转到文件内符号
- `Ctrl + T`：搜索工作区符号
- `F12`：转到定义
- `Alt + F12`：预览定义
- `Shift + F12`：查看所有引用
- `F2`：重命名符号
- `Ctrl + Tab`：切换打开的文件
- `Ctrl + PageUp`：切换到上一个标签页
- `Ctrl + PageDown`：切换到下一个标签页
- `Ctrl + 1 / 2 / 3`：聚焦第 1/2/3 个编辑器组
- `Ctrl + Shift + \`：跳转到匹配括号

## 搜索与替换

- `Ctrl + F`：当前文件查找
- `Ctrl + H`：当前文件替换
- `F3`：下一个匹配
- `Shift + F3`：上一个匹配
- `Ctrl + Shift + F`：全局搜索
- `Ctrl + Shift + H`：全局替换

## 视图与面板

- `Ctrl + B`：切换侧边栏
- `Ctrl + Shift + E`：资源管理器
- `Ctrl + Shift + F`：搜索面板
- `Ctrl + Shift + G`：源代码管理
- `Ctrl + Shift + D`：运行和调试
- `Ctrl + Shift + X`：扩展
- `Ctrl + 反引号`：终端
- `Ctrl + Shift + 反引号`：新建终端
- `Ctrl + J`：切换底部面板
- `Ctrl + K Z`：禅模式
- `Esc Esc`：退出禅模式
- `F11`：全屏

## 文件操作

- `Ctrl + N`：新建文件
- `Ctrl + O`：打开文件
- `Ctrl + S`：保存
- `Ctrl + K S`：全部保存
- `Ctrl + Shift + S`：另存为
- `Ctrl + W`：关闭当前编辑器
- `Ctrl + K W`：关闭所有编辑器
- `Ctrl + Shift + T`：重新打开刚关闭的文件

## 调试

- `F5`：启动/继续
- `Shift + F5`：停止调试
- `F9`：切换断点
- `F10`：单步跳过
- `F11`：单步进入
- `Shift + F11`：单步跳出
- `Ctrl + Shift + F5`：重启调试

## 格式化与智能提示

- `Shift + Alt + F`：格式化整个文档
- `Ctrl + K Ctrl + F`：格式化选中部分
- `Ctrl + Space`：触发建议
- `Ctrl + Shift + Space`：参数提示
- `Ctrl + .`：快速修复
- `F2`：重命名符号

## 其他实用

- `Ctrl + ,`：打开设置
- `Ctrl + K Ctrl + S`：打开键盘快捷方式
- `Ctrl + K Ctrl + T`：切换主题
- `Ctrl + Shift + P`：命令面板
